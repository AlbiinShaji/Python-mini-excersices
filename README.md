# Python Mini Exercises

A collection of small Python exercises completed as part of internship onboarding, covering core language fundamentals: control flow, string manipulation, functions, comprehensions, file I/O, and object-oriented programming.

## Contents

| File | Concept |
|---|---|
| `1_fizzbuzz.py` | Loops, conditionals, modulo operator |
| `2_palindrome_checker.py` | String manipulation, regex |
| `3_word_frequency_counter.py` | Dictionaries, `collections.Counter` |
| `4_simple_calculator.py` | Functions, dictionaries as dispatch tables |
| `5_comprehensions.py` | List and dict comprehensions |
| `6_file_read_write.py` | File I/O, CSV handling |
| `7_bank_account_class.py` | Classes, OOP, state management |

## How to run

Each file is self-contained and can be run directly:

```bash
python 1_fizzbuzz.py
python 2_palindrome_checker.py
python 3_word_frequency_counter.py
python 4_simple_calculator.py
python 5_comprehensions.py
python 6_file_read_write.py
python 7_bank_account_class.py
```

Requires Python 3.7+. No external dependencies.

## About

These exercises were completed to demonstrate comfort with Python fundamentals before moving on to framework-specific work (Django/Flask) and API development.
